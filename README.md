# Her Haven - Luxury Boutique & Salon

## Project Overview
**Her Haven** is a full-stack web application for a Luxury Boutique & Salon. It allows customers to explore beauty and salon services, browse boutique collections, and book appointments seamlessly through a modern, responsive interface.

## Features
* **Luxury Salon & Boutique Showcase:** Detailed catalog of salon treatments, beauty packages, and boutique offerings.
* **Appointment & Booking System:** Easy scheduling and inquiry management powered by backend APIs.
* **Responsive Modern UI:** Built with Vite and TypeScript for a fast, smooth user experience across all devices.

## Tech Stack
* **Frontend:** React, TypeScript, Vite, CSS
* **Backend:** Node.js / Express (or Python - *jo aapne use kiya ho*)
* **Tools & Deployment:** GitHub, Vercel / Render

## Project Structure
```text
├── her_haven_frontend/    # Client-side UI and components
├── her_haven_backend/     # Server-side APIs and backend logic
└── README.md              # Project documentation and setup guide
```

## How to Run the Project Locally

### 1. Clone the Repository
```bash
git clone https://github.com
```

### 2. Run the Backend
```bash
cd her_haven_backend/her_haven_backend
npm install
npm start
```

### 3. Run the Frontend
Open a new terminal and run:
```bash
cd her_haven_frontend/her_haven
npm install
npm run dev
```
